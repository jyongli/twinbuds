# 同听实施计划

1. 建立最小 Android 工程（Java，minSdk 21，compile/target 36），固定 Gradle / AGP 版本，复用本机 SDK 与 JDK，不修改全局配置。
2. 先为兼容性判断编写失败测试，再实现纯 Java 状态判断。两台连接、厂商名或 LE Audio 能力均不能作为双输出成功证据。
3. 实现生命周期内的蓝牙设备与系统输出读取，Android 12+ 权限请求及异常降级；实现系统设置入口和逐品牌操作指引。
4. 通过测试建立试听会话与音频生成行为，再接入媒体音频播放、音频焦点、退出停止和人工反馈。连接变化使结果失效。
5. 完成中文原生界面、无障碍标签、应用图标和本地报告；仅用户主动复制或分享，无联网权限。
6. 运行单元测试、Android Lint、assembleDebug 和签名验证；使用可用模拟器安装、操作并截图。补齐 README、设备测试清单、APK 及源码包。

主要模块：`CapabilityAdvisor`、`ListeningSession`、`TonePcm`、`DeviceMonitor`、`TestTonePlayer`、`ReportFormatter`、`MainActivity`。

验证命令（建成后）：`gradlew.bat testDebugUnitTest lintDebug assembleDebug`；构建使用 JDK 17 与本地 SDK，二者不写入源码包。没有原始代码和既有测试基线。不发布应用商店，不改系统路由策略。
