# 同听：双蓝牙耳机兼容助手

用户于 2026-10-13 确认普通安装版范围：以 Android 5.0 及以上为基础兼容目标；通过设备已有的双音频能力播放，不承诺所有手机或耳机支持。交付源码与可安装 APK。

## 使用路径

1. 查看兼容性说明，按需授予 Android 12+ 的附近设备连接权限。
2. 查看实际连接的 A2DP / LE Audio 设备和系统可见音频输出。已配对设备不等于已连接设备；已连接两副耳机不等于双路播放成功。
3. 通过公开的蓝牙设置入口连接耳机，再按三星 Dual Audio、LE Audio 或通用指引，在系统界面启用共享。无稳定公开接口的厂商设置由用户手动打开。
4. 播放短提示音，询问两位听者的实际结果，明确标注为“用户试听反馈”。Android 16+ 可补充本次测试音的实际路由信息，但不会据此承诺其他应用的声音都能同样输出。
5. 在本地查看、复制或由用户主动分享兼容性报告。报告不包含蓝牙地址。

## 实现边界

- 原生 Java / Android Views，无网络、录音、位置、后台常驻或系统修改权限。
- 状态采集、兼容性判断、试听播放、报告和界面分别实现；新接口按 API 版本隔离。
- 同一测试音走系统媒体路由，不创建两条伪独立音轨，不修改用户音量。
- 双音频由操作系统持续工作，助手不需要后台保活。离开界面立即终止测试并清除本轮验证状态。
- 权限拒绝、蓝牙关闭、设备缺失、检测失败均给出对应可操作说明；厂商名及 LE Audio 支持只作为指引依据。
- 连接组合变化后清除此前试听结论，禁止把旧结果展示为当前成功。

## 验收

- JVM 测试覆盖保守的兼容性判断、试听状态失效、报告隐私与提示音数据。
- Android Lint、APK 编译与签名检查。
- 在可用模拟器上检查安装启动、拒绝权限、设置跳转、无蓝牙设备状态和布局；模拟器不作为双耳机硬件成功证据。
- 真机上分别确认两副耳机同时听到测试音及第三方媒体、断连重连、系统切换输出。当前无已确认可用的真机耳机组合，此项交付时明确留待设备验证。
